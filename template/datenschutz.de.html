Was diese Seite lädt

Schriften, Bilder, Stylesheet und der Kartenbaustein liegen auf demselben Server wie die Seite. Es gibt keine Cookies, keine Reichweitenmessung, keine Schriften von Google Fonts und keine Bausteine sozialer Netzwerke. Eine Prüfung im Bauablauf hält das fest: findet sie eine Adresse, die auf einen fremden Server zeigt, bricht der Bau ab und es wird nichts veröffentlicht.

Eine Ausnahme ist eingetragen, und sie ist der Grund für den Knopf auf der Karte: die Kartenbilder kommen von tile.openstreetmap.org, betrieben von der OpenStreetMap Foundation.
